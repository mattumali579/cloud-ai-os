# Gesture hologram HUD

Local webcam demo for GitHub issue #29. Isolated from Jarvis glasses work.

## Start

```powershell
cd C:\Users\mattu\cloud-ai-os\apps\gesture-hud
npm install
npm test
npm run dev
```

Open http://127.0.0.1:5177/

Press **Start camera**, allow the webcam, pinch thumb and index on both hands, then drag, stretch, or tilt the glass panel. Release to freeze. Reset restores the default pose. Nothing is recorded or uploaded.
