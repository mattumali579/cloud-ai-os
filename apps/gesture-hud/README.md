# Gesture hologram HUD

Local webcam demo for GitHub issue #29. Isolated from Jarvis glasses work.

## Start

```powershell
cd C:\Users\mattu\cloud-ai-os\apps\gesture-hud
npm install
npm test
npm run dev
```

Open http://127.0.0.1:5177/

Press **Start camera**, allow the webcam, then hold both hands up. A colored portal stretches between your fingertips. Drop a hand to hide it. Press **Next look** to cycle colors. Nothing is recorded or uploaded.
