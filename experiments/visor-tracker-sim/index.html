Click the view, then look with the mouse. WASD moves. Keys 1 and 2 select the mode. The center ray is a simulated finger, not the glasses ray.

H hide the locked object. R restore it. M start or stop object motion. Arrow keys slide the objects.

If the locked object is hidden or leaves the view, the next lock is the visible object closest to the screen center. That is this page's rule. It is not the Kotlin finger ray.

Known replacement: 2 ticks when another object is already visible. Nothing visible: hold 3 ticks. A finger lock stays when the ray hits nothing. Kotlin and this page do not share an executable.
